# Каждый джоуль — Every Joule (русская редакция)

Интерактивная 3D-книга по физике об энергии: десять уроков, от пружин до электростанций.
Каждый рисунок поднимается со страницы, а энергия перетекает светящимся цветом между запасами.

Это русская редакция книги [Every Joule](https://iamtechartist.com/every-joule/) (© Techartist).
Оригинал: https://iamtechartist.com/every-joule/

## Что внутри

- `index.html` — интерактивная 3D-книга (three.js).
- `teachers.html` — заметки для учителя.
- `sources.html` — источники всех чисел.
- `assets/` — скрипты, стили и шрифты.

Цитаты спецификаций экзаменационных советов на странице для учителя оставлены на языке оригинала — это дословные формулировки. Остальной интерфейс и текст книги переведены на русский.

## Локальный запуск

```sh
python3 -m http.server 8000
```

Откройте http://localhost:8000/
